BULWARKPortal

Privacy

Last updated November 15, 2026.

What Bulwark stores

Account email, name, password hash (scrypt), organization name and sector. Session and runner tokens as SHA-256 hashes. GitHub tokens encrypted with AES-256-GCM. Alert webhook URLs encrypted the same way. Repository names, scan records, findings (rule, file path, line, message), the dependency list of each scan (package names and versions) and an audit log of account actions.

Source code

Cloud scans read repository files through the GitHub API into memory for the length of one scan. File contents are not written to disk or the database. Fix pull requests read and write only the file being fixed. Bulwark Edge never sends source code; in connected mode it sends findings, a heartbeat and the package names and versions from lockfiles. In air-gapped mode it sends nothing.

Third parties

Render (hosting and database, United States), GitHub (repository access you grant), OSV.dev (package name and version lookups), CISA (download of the public Known Exploited Vulnerabilities catalog; nothing is sent), the alert webhook you configure (repository name, commit and finding counts) and, when model patches are enabled, Anthropic (the single file being fixed). No advertising or analytics trackers.

Deletion

Disconnecting GitHub deletes the stored token immediately. Portal, Settings, Delete organization removes the account, repositories, scans, findings, runner tokens and audit log at once.
