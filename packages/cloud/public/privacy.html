BULWARKPortal

Privacy

Last updated November 15, 2026.

What Bulwark stores

Account email, name, password hash (scrypt), organization name and sector. Session and runner tokens as SHA-256 hashes. GitHub tokens encrypted with AES-256-GCM. Repository names, scan records, findings (rule, file path, line, message) and an audit log of account actions.

Source code

Cloud scans read repository files through the GitHub API into memory for the length of one scan. File contents are not written to disk or the database. Fix pull requests read and write only the file being fixed. Bulwark Edge never sends source code; in connected mode it sends findings, a heartbeat, and for the dependency module the package names and versions from lockfiles. In air-gapped mode it sends nothing.

Third parties

Render (hosting and database, United States), GitHub (repository access you grant), OSV.dev (package name and version lookups) and, when model patches are enabled, Anthropic (the single file being fixed). No advertising or analytics trackers.

Deletion

Disconnecting GitHub deletes the stored token immediately. To delete an account and all its data, email the address on your invoice or open an issue at github.com/hunterh37/Bulwark.
