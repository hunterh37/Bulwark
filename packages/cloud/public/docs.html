CI gate (GitHub Actions)

No account needed. The runner scans the checkout, fails the job at the chosen severity and writes SARIF for GitHub code scanning.

- uses: actions/checkout@v4
- uses: hunterh37/Bulwark@main
  with:
    fail-on: high
- uses: github/codeql-action/upload-sarif@v3
  if: always()
  with:
    sarif_file: bulwark-results

Command line

curl -O https://bulwark-cloud.onrender.com/download/bulwark-runner.mjs
node bulwark-runner.mjs scan . --offline --list --fail-on high

Writes bulwark-results/<repo>.json, .sarif and .cdx.json (CycloneDX 1.5 SBOM). Needs Node 20 or later, no other dependency.

FlagEffect
--offlineNo network. Dependency advisories are skipped.
--osvLook up dependency advisories at OSV.dev and the CISA KEV catalog directly. Sends package names and versions.
--fail-on critical|high|mediumExit 2 when a finding at or above the level is in non-test code.
--listPrint each finding. Add --include-tests for test, example and third-party paths.
--repo, --outRepository name in the results and the output directory.

Cloud

Create an account, add a repository as owner/name and press Scan now. Public repositories scan without a token. Private repositories and fix pull requests need a fine-grained GitHub token: Contents read and Metadata read to scan, plus Contents write and Pull requests write to open fix PRs. Repositories rescan on the interval set under Settings (daily by default), and new high or critical findings post to the alert webhook.

Edge runner

export BULWARK_URL=https://bulwark-cloud.onrender.com
export BULWARK_TOKEN=bwr_…            # Portal, Edge runners, Create runner token
node bulwark-runner.mjs watch /srv/git/scada-hmi --every 3600

Connected mode sends findings (rule, file path, line, message), the component list (package names and versions) and a heartbeat. Source code is not sent. Air-gapped mode (--offline) sends nothing.

Reading findings

Each finding has a rule id, CWE id, file, line, severity and a fingerprint. The fingerprint is built from the rule, the path and the matched text, so a finding keeps its status (ignored, PR open) and first-seen date when lines move. Findings in test, example, documentation and third-party paths are reported at low severity and hidden by default. Dependency advisories in the CISA Known Exploited Vulnerabilities catalog are raised to critical and tagged KEV.

Evidence

Portal, Overview, Evidence report opens a printable report: scope, scan dates and commits, open findings with CWE ids, fix pull requests, SBOM component counts and the audit log. Portal, GitHub, SBOM downloads a CycloneDX 1.5 file per repository. The report maps Bulwark records to IEC 62443-4-1 practice areas, the EU Cyber Resilience Act Annex I Part II and NERC CIP-013. It is input to an assessment and is not a certification.

Measured accuracy

Labeled corpus: eval/REPORT.md, run in CI on every push. Field run on 15 public OT repositories with hand labels: eval/FIELD.md.
