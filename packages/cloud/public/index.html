Security scanning for the software that runs the grid.

Bulwark reads SCADA, HMI, charger and gateway code for insecure Modbus, DNP3, IEC 61850, IEC 60870-5-104, OCPP, OPC UA and BACnet configuration, default credentials, leaked secrets and vulnerable dependencies. It opens a verified fix pull request and keeps the SBOM and evidence report an assessor asks for.

How it works

1. Scan

In GitHub Actions on every pull request, in Bulwark Cloud on a schedule, or on an Edge runner next to an on-prem Git server.

2. Rank

Findings carry a CWE id and a grid-impact flag. Dependency advisories in the CISA Known Exploited Vulnerabilities catalog go to the top. Test and example code is kept out of the count.

3. Fix

Bulwark patches the line, rescans the patched file and opens a pull request when the finding is gone and nothing new appears. Your CI runs on the branch.

4. Prove

CycloneDX SBOM per repository and a printable evidence report with scan dates, commits, findings, fixes and the audit log.

Bulwark Edge for plant networks

One file, Node 20+, zero dependencies. Runs on a jump host, in the OT DMZ, or fully air-gapped.

Connected

Outbound HTTPS 443 only. Sends rule, file path, line and the package list. Never source.

Air-gapped

No network. Writes JSON, SARIF and a CycloneDX SBOM for transfer by approved media.

Packaging

Single-file runner, signed Docker image, docker compose, systemd installer, SHA-256 sums.
