# Pitch lines (grid-dependent focus)

1. Bulwark is an always-on cloud security layer for companies that run the power grid
   and the software it depends on. It watches your GitHub repos and ships tested,
   reviewed fixes before attackers find the gap.

2. Utilities and energy software teams connect GitHub once; Bulwark scans every change,
   writes the patch, proves it passes your tests, and opens the PR.

3. Always-on AppSec for grid-dependent software: find the vulnerability, write the fix,
   prove it is safe, ship it as a PR.
